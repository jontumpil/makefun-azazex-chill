# One Line, One Chill

One horror sentence, under 200 characters, that frightens in a single
breath. A child's drawing of the family holds one figure too many, and
the fifth one is the narrator himself, dated tomorrow.

## The line

> My son's drawing of our family has four figures, and when I asked who the fifth one holding my hand is, he said, "You, tomorrow".

129 characters, one sentence.

## Run

```sh
python3 main.py
```

Writes the line to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Standard library only, deterministic.
